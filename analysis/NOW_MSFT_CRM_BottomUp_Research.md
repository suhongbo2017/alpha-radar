## 0. 研究结论速览

| 维度 | NOW (ServiceNow) | MSFT (Microsoft) | CRM (Salesforce) |
|---|---|---|---|
| **一句话定位** | AI 时代企业工作流的"手" | AI 时代算力+分发的"收费站" | 客户数据与记录的"账本" |
| **最大瓶颈角色** | 工作流/执行权 | 算力、电力、模型分发 | 客户上下文与数据 |
| **增长（最新季度）** | **+24.0%** | +18.3% | +10.8% |
| **增速趋势** | 稳（20→24%） | 加速（14%→18%） | 稳但结构分化 |
| **领先指标（RPO）** | +21.3% | **+84%** | +10.7%（且非流动 RPO 下滑） |
| **ROIC vs WACC** | 10.3% vs 9.2% ⚠️ | **26.2% vs 10.0%** ✅ | 11.0% vs 9.4% ⚠️ |
| **FCF 利润率** | 31% | **20%**（被 capex 吞噬） | **34%** |
| **净债务** | $1.8B | $52.0B | **$31.0B（杠杆最重）** |
| **利息覆盖** | 22x | **50x** | 9.4x ⚠️ |
| **Forward PE** | 30.5x | 26.8x | **15.7x** |
| **EV/FCF** | 31.5x | **59.5x** ⚠️ | **14.2x** ✅ |
| **52 周涨跌** | **-24.4%** | +2.3% | -6.4% |
| **一致预期下一年 EPS 增速** | +23.1% | +19.8% | **-4.4%** ⚠️ |

**核心判断（先给结论，再给推导）：**

1. **三家公司面对的是同一个问题——"AI 重分配软件业利润"——但站位完全不同。** MSFT 站在瓶颈上游（算力+企业分发），NOW 站在执行层（工作流+权限+数据），CRM 站在记录层（客户数据账本）。按 skill 第 7 节框架：MSFT ≈ AI 基础设施型 + AI 增强型；NOW ≈ AI 增强型；CRM ≈ 被攻击面最大的"AI 替代型/需重构型"。
2. **市场已经把大量未来写进 MSFT 的价格（EV/FCF 59.5x），把少量未来写进 CRM 的价格（EV/FCF 14.2x）。** 方向性机会在两端，中间是 NOW。
3. **三家里"财务质量"排序：MSFT >> NOW ≈ CRM**（ROIC、利息覆盖、现金转化）。三家里"估值隐含预期"排序：CRM < NOW < MSFT。
4. **本报告倾向：NOW 的风险收益比最好（已被市场杀过 24%，预期已下调，而基本面 RPO/客户数仍在 20%+）；MSFT 是最优质的资产但价格已含高预期，且 FCF 正被 capex 吞噬，本质是"对 AI 投资回报的期权"；CRM 是最便宜的期权，但便宜有原因——增长结构在分化、杠杆在上升、非 GAAP EPS 预期在 FY2028 转负。**

## 1. 第一层：世界发生了什么？

**事实链（来自一手数据，非叙事）：**

| 证据 | 数值 | 含义 |
|---|---|---|
| MSFT 商业 RPO | **$678B，+84% YoY**（FY2026 10-K） | 企业已签下未确认的合同义务出现史无前例的跳升 |
| MSFT Azure | **+41%**（FY2026） | 算力需求仍在加速，不是放缓 |
| MSFT capex | **$115.9B**（FY2026）vs FY2025 $64.6B（**+80%**） | 供给端在疯狂扩产 |
| MSFT capex / OCF | **63%** | 一家软件公司把 2/3 的经营现金流投回基建 |
| NOW 商誉 | $3.58B → **$9.84B**（半年） | 应用层公司在用并购补齐 AI/安全能力 |
| CRM 总收入增速 | **9.6%**（FY2026），核心 Agentforce Apps 仅 **+7.6%** | 传统 SaaS 核心在失去增速 |
| CRM 有息负债 | $10.4B → **$39.3B**（一个季度） | 用债务买回股票，资本结构剧变 |

**结论：世界正在发生的是「AI 资本开支周期 + 企业预算从"座位/功能"向"算力/数据/执行"迁移」。**

这不是"AI 会不会取代 SaaS"的问题，而是：

> **软件业的利润正在从"功能授权"重新分配到"算力供给"与"执行结果"。**

---

## 2. 为什么发生？（因果链，而非新闻）

```
模型能力提升
  → AI 可以完成过去需要人点击 UI 完成的任务
  → 软件的价值锚点从「界面 + 功能」转向「数据 + 权限 + 执行」
  → 企业开始为「token/算力/结果」付钱，而不是为「座位」付钱
  → 算力成为新的稀缺品 ⇒ 资本涌入数据中心
  → 数据中心需要电、地、芯片、许可（制度瓶颈）
  → 应用层必须证明自己不是"可被 Agent 绕过的 UI"
```

**关键推论（skill 第 5 节：瓶颈迁移）：**

- 旧瓶颈：软件功能
- 新瓶颈：**算力、电力、企业数据质量、执行权限**
- 下一个瓶颈（正在形成）：**可信的企业上下文 + 审计 + 权限体系**

## 3. 价值链与利润流向

```
[能源/土地/许可] → [芯片/HBM] → [数据中心] → [云平台] → [模型/Agent 框架]
                                                              ↓
                            [工作流/执行层] ←→ [系统 of Record（客户/财务/IT）]
                                                              ↓
                                                     [最终企业客户]
```

| 环节 | 代表 | 议价权 | 证据 |
|---|---|---|---|
| 数据中心/云平台 | **MSFT** | 极强 | Azure +41%，capex 一年 $116B 形成资本壁垒 |
| 工作流/执行 | **NOW** | 强 | 98% 续约率，ACV>$5M 客户 +23.5% |
| 系统 of Record | **CRM** | 中→弱 | 核心 +7.6%，但 RPO 非流动部分在收缩 |
| 模型层 | OpenAI 等 | 强但不可投资 | MSFT 通过投资+IP 权利间接持有 |

**利润流向判断：**
- 短期（1-3 年）：**利润流向算力持有者（MSFT）**。RPO +84% 是最硬的证据。
- 中期（3-7 年）：**利润流向"拥有企业数据和执行权限"的一方**。这是 NOW 与 CRM 的战场。
- 风险：若算力过剩（capex 转为折旧），利润会从 MSFT 回流到应用层。

## 5. 逐公司深度分析

### 5.1 NOW（ServiceNow）—— $137.97 / 市值 $142.6B

#### 生意与护城河

- **业务本质**：企业 ITSM/工作流平台。四类应用：Technology、CRM & Industry、Core Business、Creator。
- **护城河来源**：
  1. **工作流嵌入**：一旦流程跑在 ServiceNow 上，迁移等于重做企业流程 → 98% 续约率，且是 3 年合同。
  2. **数据模型统一**："single data fabric + integrated data layer" —— 这是 AI 最需要的上下文。
  3. **大客户锁定**：ACV > $5M 的客户 **658 家（+23.5% YoY）**，说明企业级渗透仍在加速，不是饱和。

#### 关键财务事实（一手）

| 项目 | FY2025 | H1 2026 | 说明 |
|---|---:|---:|---|
| 收入 | $13.278B (+20.9%) | $7.757B | Q2'26 单季 +24.0% |
| GAAP 营业利润 | $1.824B (13.7%) | $0.665B (8.6%) | Q2'26 仅 $162M (4.1%) |
| **Non-GAAP 营业利润** | — | **$2.372B (30.6%)** | Q2'26 $1,173M (29.4%)，同比 +23% |
| OCF | $5.444B | **$2.257B（-6% YoY）** ⚠️ | TTM OCF $5.31B < FY2025 |
| FCF（公司 Non-GAAP 口径） | $4.576B | $2.299B (+14%) | 增速 < 收入增速 |
| RPO | $28.2B | **$29.0B（+21.3% YoY）** | 46% 将在 12 个月内确认 → cRPO ≈ $13.3B |
| SBC | $1.955B (14.7%) | $1.213B (15.6%) | 稀释成本高 |

**GAAP 利润暴跌的真相（重要）**——不是经营恶化：

```
Q2'26 GAAP 营业利润 $162M
  + SBC                        $655M
  + 收购无形资产摊销            $219M   (去年仅 $25M)
  + 并购相关费用                 $75M
  + 遣散费                       $62M
  ─────────────────────────────
  = Non-GAAP 营业利润         $1,173M  (29.4% 利润率，同比 +23%)
```

**但真正的黄牌在这里**：

> H1 2026 OCF $2,257M，**同比 -6%**，而收入 +23%。
> TTM OCF $5.31B < FY2025 全年 $5.44B。
> 也就是说：**收入在增长，现金在倒退。**

原因包括并购相关现金支出（$297M）与收款节奏，但这与"软件公司应该现金越高越好"的直觉相悖，需要后续季度验证。

#### 资本配置：最值得警惕的一点

12 个月内连续收购：

| 时间 | 标的 | 金额 | 用途 |
|---|---|---:|---|
| 2025-05 | Logik.io | 小额 | CPQ |
| 2025-12 | **Moveworks** | **$2.4B** | 企业搜索 / 前端虚拟 Agent |
| 2026-03 | **Veza** | **$1.2B** | AI 身份安全 |
| 2026-04 | **Armis** | **$7.6B** | 网络暴露面管理 |
| | **合计** | **≈ $11.4B** | |

后果：
- 商誉 $3.58B → **$9.84B**；无形资产 $1.12B → $3.78B
- 长期债务 $1.49B → **$5.44B**；短债 $0 → $2.08B（发债：1.40%'30 / 4.25%'28 / 4.70%'31 / 5.05%'33 / 5.40%'36 / 6.30%'56）
- **ROIC 被稀释到 10.3%，仅比 WACC 9.2% 高 1.1pp**

> skill 第 3 节：横跨高回报行业的资本涌入会压低回报率。NOW 正处在这个规律的负面一侧——**用高价并购买增长，回报率贴着资本成本**。

另有 5:1 拆股（2025-12-17 生效，故当前 10.3 亿股），$2.0B ASR（均价 $107.97，1850 万股）+ $225M 公开市场回购；2026-01 新增 $5B 回购授权。

#### AI 验证（skill 第 11 节）

| 问题 | 证据 | 判定 |
|---|---|---|
| AI 是否带来新增 ARR？ | 10-Q 中**未单独披露** AI/Now Assist 的 ACV 或 ARR | ❓ 不透明 |
| AI 是否提升 ARPU？ | 未量化。ACV>$5M 客户 +23.5% 是间接正面信号 | 🟡 间接 |
| AI 是否改善留存？ | 续约率 98%，同比持平 | 🟡 中性 |
| AI 是否降低成本？ | Non-GAAP 利润率 29.4% vs 29.7%，**持平略降** | 🔴 未见 |
| AI 是否改善 FCF？ | H1 OCF **-6%** | 🔴 尚未 |

**结论：NOW 的 AI 叙事在收入端尚未被财务数据证实。** 按 skill 第 11 节："如果只有使用量增长，而没有经济价值证据，应保持谨慎。"

#### 市场预期（skill 第 12/13 节）

- 股价 **-24.4%**（52 周），从高点 $192.97 跌至 $137.97
- Forward PE 30.5x，PEG 1.25
- 一致预期：FY2026 收入 $16.22B (+22.1%)，Non-GAAP EPS $4.07 (+15.9%)；FY2027 收入 $19.26B (+18.8%)，EPS $5.01 (+23.1%)
- 目标价 $146.73（+6.35%），区间 $72 ~ $248
- 分析师情绪：35 Strong Buy / 10 Buy / 2 Hold / 2 Sell — **但过去 5 个月出现 1 家下调至 Sell，说明分歧在扩大**

**当前价格隐含什么？**

```
$137.97 = FY2027 Non-GAAP EPS $5.01 × 27.5x
         = FY2026 FCF $5.65B 的 25.2x P/FCF（FCF yield 3.96%）
```

→ 市场隐含：**未来 5 年收入 CAGR ≈ 14-16% + FCF 利润率维持 30%+，且不再大额并购。**
→ 这**低于**公司历史 20-24% 的增速，也低于一致预期 18.8%。
→ **差距存在，但是"温和的差距"，不是"巨大的错杀"。**

#### Bull / Base / Bear（5 年至 FY2031）

| 情景 | 概率 | 假设 | FY2031 收入 | FCF 利润率 | FCF | 倍数 | 目标市值 | 目标价 |
|---|---:|---|---:|---:|---:|---:|---:|---:|
| **Bull** | 25% | AI 成为新交互层，NOW 拥有执行权；增速回到 20%+；并购消化良好 | $40.4B | 35% | $14.1B | 28x | $396B | **$384** |
| **Base** | 50% | 增速自然衰减至 15%；利润率稳中略升；AI 贡献渐进 | $30.6B | 32% | $9.8B | 22x | $215B | **$209** |
| **Bear** | 25% | Agent 绕过 UI，工作流商品化；ROIC 继续被并购稀释；OCF 持续不增长 | $22.3B | 27% | $6.0B | 14x | $84B | **$82** |

**概率加权价值 ≈ 0.25×384 + 0.50×209 + 0.25×82 = $221**（当前 $137.97）
→ 隐含 5 年 CAGR ≈ **9.9%**，加上回购/无股息 → 总回报 ≈ 10-11%/年

#### 失效指标（Invalidation，必须提前定义）

1. **RPO 增速连续两个季度 < 15%**（当前 21.3%）→ 需求侧转弱
2. **ACV > $5M 客户数增速跌至 < 12%**（当前 23.5%）→ 大企业渗透见顶
3. **续约率跌破 97%** → 护城河出现裂缝
4. **Non-GAAP 营业利润率跌破 28%** → AI 带来的成本未被收入覆盖
5. **再有 > $5B 的并购，且 ROIC 继续下行** → 资本配置失控
6. **TTM OCF 连续四个季度同比负增长** → 现金转化结构性恶化

### 5.2 MSFT（Microsoft）—— $529.30 / 市值 $3.93T

#### 生意与护城河

- **业务本质**：三层结构 —— 应用（M365/Dynamics/LinkedIn）+ 云与 AI 基建（Azure）+ 端（Windows/Xbox/广告）
- **护城河来源**：
  1. **企业分发渠道**：M365 是地球上最大的企业软件安装基数 → Copilot 的天然分发
  2. **资本壁垒**：FY2026 capex $116B，这个数字本身就是护城河
  3. **切换成本**：Entra ID / AD、Office 文件格式、Teams 组织架构
  4. **OpenAI 关系**：2025-10、2026-04 两次延长合作，持有 IP 权利 + 收入分成

#### 关键财务事实

|---|---:|

| 2025-06-30 | $375B |
| 2025-09-30 | $398B |

> 单季 +$233B 的跳升（2025 Q4）必然包含超大额长期承诺（OpenAI 相关可能性高，但 MSFT 未做客户集中度量化披露）。

**核心矛盾：**

> MSFT 的收入因 AI 加速（17.8%），但**自由现金流连续三年下降**。

**一致预期已经把这个矛盾显性化了：**
- FY2027 一致预期 FCF = **$32.9B**（不足 FY2026 $67.0B 的一半）
- 意味着 **P/FCF ≈ 119x**（当前市值 3.93T / 32.9B）

- SBC：$12.4B（占收入 3.7%，三家中最优）

### 5.3 CRM（Salesforce）—— $224.99 / 市值 $185.2B

#### 生意与护城河

- **业务本质**：Agentforce 360 Platform（原 Customer 360）+ Data 360（含 Informatica）
- **护城河来源**：
  1. **客户数据（System of Record）**：客户、商机、服务工单、历史互动
  2. **流程嵌入**：销售/服务流程的工作流
  3. **AppExchange 生态**
- **护城河弱点**：
  - 数据虽多，但**并非独家**（企业自己也有）
  - **CRM 是"最容易被 Agent 绕过"的一层**——Agent 可以直接读数据库、直接发邮件、直接改工单，不需要经过 Salesforce UI

#### 关键财务事实——**结构性分化的证据（最重要发现）**

CRM 从 FY2027 Q1 开始**重新分类订阅收入**，这是最有价值的一手披露：

> **这是本报告最有价值的单一发现。**

> 也就是说：CRM 的增长故事已经从"卖 CRM 座位"变成"卖数据平台"。
> 如果按 skill 第 7 节的分类，**Agentforce Apps 正是典型的"AI 替代型软件"——功能化、可被绕过、增速最低。**

```
                    谁控制瓶颈？
                        │
   ┌────────────────────┼────────────────────┐
   │                    │                    │
 算力/基建            执行/工作流          记录/数据
 【MSFT】             【NOW】              【CRM】
 RPO +84%            RPO +21%             RPO +11%
 Azure +41%          续约率 98%            核心 +7.6%

 capex 吞噬 FCF      并购稀释 ROIC         债务回购
   │                    │                    │

   │                    │                    │
```

**按 skill 第 7 节的 AI 软件三分类：**

| 类型 | 定义 | 三家公司对应 |
|---|---|---|
| **AI 基础设施型** | 拥有企业数据、工作流、权限、API、审计、身份、生态 | **MSFT ✅**、**NOW ✅**（较弱）、CRM 🟡（有数据但无执行权） |
| **AI 增强型** | AI 提升产品能力、效率、ARPU | MSFT（Copilot）、NOW（Now Assist）、CRM（Agentforce） |
| **AI 替代型** | 简单功能、低转换成本、缺数据壁垒 | **CRM 的 Agentforce Apps 部分最接近** ⚠️ |

**关键回答（skill 第 9 节）："AI 是绕过 SaaS，还是成为 SaaS 的新交互层？"**

- **对 MSFT**：AI 不需要绕过任何东西 —— 它**就是** AI 的载体。MSFT 拥有模型权利、算力、分发。
- **对 NOW**：AI **成为**了新交互层，而 NOW 拥有"执行权"和"权限体系"。**这是最强的定位。**
- **对 CRM**：**这是最危险的一侧。** Agent 可以直接读客户数据库、直接操作，绕过 CRM UI。CRM 正在用 Data 360（数据治理层）和 Informatica（元数据/主数据）**主动给自己重新定位成"AI 的数据底座"**——这是正确的战略反应，但目前收入证据（Data 360 +20.3% vs 核心 +7.6%）说明转型还没完成，且旧核心在下滑。

## 7. 反证与失败条件（skill 第 12 节）

## 9. 三选一的决策矩阵

| 若你的判断是…… | 选择 | 理由 |
|---|---|---|
| AI 的瓶颈是算力，且愿意为确定性付溢价 | **MSFT** | RPO +84%、Azure +41%、ROIC 26%。**但等回调，不要在 RSI 68、EV/FCF 59x 时买入** |

**一句话版本（skill 第 19 节）：**

> **世界正在把软件业的利润从"功能"重新分配到"算力 + 执行 + 数据"。MSFT 持有算力（已在价内），NOW 持有执行权（已打折 24%），CRM 持有数据但正在丢失执行权（打 13x）。瓶颈在迁移，钱跟着瓶颈走 —— 问题不是"哪家是好公司"，而是"哪家的价格还没把这件事写进去"。**
